# omi-cli менен баштоо

Бул колдонмо кыргыз тилинде биринчи буйруктарды түшүндүрөт. Буйруктардын аталыштары жана программалык билдирүүлөр англис тилинде калат. Бул жердеги мисал суроолор сиздин эскерүүлөрүңүздү, маектериңизди, тапшырмаларыңызды же максаттарыңызды өзгөртпөйт.

## Программаны орнотуу

Талаптар: Python 3.10 же андан жаңыраак версиясы жана Omi аккаунту.

Эгер сизде pipx орнотулган болсо:

```bash
pipx install omi-cli
omi --help
```

Же болбосо, активдештирилген Python виртуалдык чөйрөсүнө орнотсоңуз болот:

```bash
python -m pip install omi-cli
omi --help
```

## Аккаунтуңузду туташтыруу

Колдонмону колдонуудан мурун аутентификациядан өтүңүз:

```bash
omi auth login
```

Браузер ачылат. Omi аккаунтуңузга кирип, уруксат бериңиз.

## Маалыматтарыңызды көрүү

Эскерүүлөрүңүздү тизмелөө:

```bash
omi memory list
```

Маектериңизди тизмелөө:

```bash
omi conversation list
```

## Чыгуу

Сеансты аяктоо үчүн:

```bash
omi auth logout
```
